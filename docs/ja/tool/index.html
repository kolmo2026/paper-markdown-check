ローカルMarkdown点検CLIを使う

これはローカルのNode CLIであり、ブラウザーから文書を送るサービスではありません。ソースを取得し、自分のファイルに対して実行します。Node 24以降が必要です。

git clone https://github.com/kolmo2026/paper-markdown-check.git
cd paper-markdown-check
npm ci
node src/cli.js examples/clean-paper.md
node src/cli.js examples/broken-paper.md --json
npm test

不備のあるサンプルは意図的に終了コード1を返します。構文はnode src/cli.js --helpで確認できます。文書への書き込みや外部リンクへのアクセスは行いません。診断メッセージは英語です。
