論文を研究ノートに取り込む前に、Markdownの構造を点検する

kolmo2026保守チーム · 運営・関連性の開示

公開 2026-11-03 · 更新 2026-11-04

編集上の更新：方法記事で関連製品への案内を明確化し、保守者、日付、同サイトの関連記事を追加しました。計算やファイル処理の動作は変更していません。

論文をMarkdownに変換したら、画像などの資源も一緒に移動したか確認します。本文が読めても、参照先の図が欠けると、説明を支える情報が失われます。ここでは顧客文書ではなく合成データを使います。

インストールして実行する

git clone https://github.com/kolmo2026/paper-markdown-check.git
cd paper-markdown-check
npm ci
node src/cli.js examples/broken-paper.md

Node 24以降を使用します。依存関係のインストールには通信が必要ですが、その後のローカル点検では通信しません。サンプルには次の行があります。

# Paper
### Methods

Text.

![Pipeline](figures/pipeline.png)

[Dataset][data]

報告を読む

WARNING line 2 [heading-jump] Heading level jumps from 1 to 3: Methods
ERROR line 6 [missing-file] Missing local file: figures/pipeline.png
ERROR line 8 [undefined-reference] Undefined explicit reference: data
2 errors, 1 warnings

見出しの警告は読みやすさの問題であり、変換失敗の証明ではありません。一方、存在しないローカルパスと未定義の参照は機械的に確認できるエラーです。エラーがあるため終了コードは1になります。ツールはファイルを変更せず、代わりの図も作りません。CLIの診断文は英語です。

根拠のある修正だけを行う

  1. 意図した章構成に合うなら、Methodsをレベル2に変更します。
  2. 本来の図を相対パスに戻すか、実在するファイルへのパスに直します。検査を通すためだけに空画像を置かないでください。
  3. [data]: https://data.invalid/exampleのように参照先を定義します。この予約済みの例示アドレスは合成データです。ツールはアクセスせず、データセットの存在も保証しません。
  4. 同梱の正常例をnode src/cli.js examples/clean-paper.md --jsonで実行します。エラーと警告がともに0になります。

先にMarkdownを生成する必要がある場合は、同じ保守エコシステムの関連製品であるKolmoPDFのクラウドPDF→Markdownサービスがあります。そちらはPDFをアップロードして処理します。この点検ツールはローカル出力を読む別物で、PDFパーサーを含みません。

あわせて読む

  • Markdownの「問題なし」で分かること、分からないこと
