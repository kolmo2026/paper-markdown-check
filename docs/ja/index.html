Markdownファイルが開けても、図がそろっているとは限りません。見出しレベルの飛び、ローカル添付の欠落、明示的な参照リンクの未定義、閉じていないコードフェンスを見える形にする点検台です。

一つの文書を読み、問題の位置を報告します。本文の書き換え、数式の正誤判定、外部URLへのアクセスは行いません。

点検するMarkdownを先に作る場合は、KolmoPDFのクラウドPDF→Markdown変換があります。そちらは文書をアップロードして変換します。この独立した点検ツールは、出力後のローカルファイルをアップロードせずに調べます。
