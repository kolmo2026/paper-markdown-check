Run the local Markdown inspector

This tool is a local Node CLI, not a browser upload service. Download the source and run it against your own file. Node 24 or newer is required.

git clone https://github.com/kolmo2026/paper-markdown-check.git
cd paper-markdown-check
npm ci
node src/cli.js examples/clean-paper.md
node src/cli.js examples/broken-paper.md --json
npm test

The broken sample intentionally exits with code 1. Use node src/cli.js --help for the command syntax. The command never writes to your document and does not fetch remote links.
