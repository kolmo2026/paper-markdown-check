Read the structure before trusting the handoff

A paper is more than its text.

A Markdown file can open successfully while its figures are missing. This inspection desk makes a few mechanical failures visible: skipped heading levels, missing local attachments, undefined explicit references and unclosed code fences.

The tool reads one document and reports locations. It does not rewrite your paper, judge a formula or request any remote URL.

Need a Markdown file to inspect? The related KolmoPDF cloud PDF-to-Markdown service, maintained by the same team, generates an initial conversion by uploading the document. This separate checker then inspects local files without uploading them.
